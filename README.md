# 🔑 Password Generator

Простой и удобный генератор паролей, написанный на **HTML, CSS и JavaScript**.

## 🚀 Функционал

- Генерация случайных паролей.
- Настройка длины пароля (от 4 до 24 символов).
- Включение/отключение:
  - строчных букв (a-z),
  - заглавных букв (A-Z),
  - цифр (0-9),
  - символов (`~!@#$%^&*()_+[]{}<>?/`).
- Индикатор надёжности пароля:
  - **weak** (слабый),
  - **mid** (средний),
  - **midStrong** (хороший),
  - **strong** (надёжный).
- Подсветка символов в пароле:
  - цифры — синим,
  - символы — оранжевым,
  - буквы в нижнем регистре — коричневым,
  - буквы в верхнем регистре — черным.
- Возможность скопировать пароль в буфер обмена одним кликом.
